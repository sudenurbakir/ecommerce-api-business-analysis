# E-Ticaret API Business Analysis Guide

Bu repo, **e-ticaret** alanında çalışan İş Analistleri için hazırlanmıştır.  
Amaç: API kavramlarını C# / ASP.NET Core ekosistemi bağlamında anlamak, dokümante etmek, gereksinim yazmak ve test etmek.

## Kimler İçin?

- E-ticaret sektöründe çalışan İş Analistleri
- C# / .NET kullanan ekiplerde çalışan BA’lar
- API’leri teknik detaya boğulmadan anlamak isteyenler

## İçerik

| Klasör | Konu |
|--------|------|
| 01-api-temelleri | E-ticaret ve C# perspektifinden API nedir? |
| 02-swagger-openapi | Swagger / OpenAPI nasıl okunur? |
| 03-e-ticaret-api-analizi | Product, Cart, Auth ve Sipariş akışı analizi |
| 04-gereksinim-yazma | User Story ve Acceptance Criteria örnekleri |
| 05-test-ve-hata | Postman, status code ve business hata senaryoları |
